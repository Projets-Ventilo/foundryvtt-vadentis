# Vadentis pour Foundry Virtual Tabletop

Système **Vadentis** pour Foundry Virtual Tabletop.

- Version du système : **2.0.4**
- Compatibilité : **Foundry VTT V12**
- Identifiant Foundry : `foundryvtt-vadentis`

## Installation

La distribution publique est prévue via le navigateur de paquets Foundry VTT et via le manifeste stable déclaré dans `system.json`.

## Documentation

Le manuel de jeu est inclus dans `documents/`. Le système contient également un tutoriel intégré et les compendiums nécessaires à Vadentis.

## Source repository and release package

This repository contains the Vadentis system source and the reasonably-sized assets used for development.
Large map and scenario image assets under `images/maps/` and `images/scenario/` are intentionally not versioned in Git because of their size. They are included in the complete Foundry-installable ZIP attached to each GitHub Release.

For a normal Foundry VTT installation, use the manifest/package release rather than cloning this repository directly.
